# Water Consumption Management System

A simple Java console application that takes household water usage details, calculates the water bill, and finds total daily consumption.

## Features

- Household details input (family members, house number, water consumed)
- Water usage status (Low, Medium, High)
- Automatic bill calculation (Rs. 100 for up to 500 litres, Rs. 200 for above)
- Total consumption from morning and evening usage
- Final result display

## Tech Stack

- Java
